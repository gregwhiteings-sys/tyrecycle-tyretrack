- Dashboard database snapshots are collected off the GUI thread. Cards refresh about once per second; live frame totals remain tied to the worker.
- Avoid repeated hourly-slot stylesheet changes when styles are unchanged.
- PERF GUI stages logs frame preparation, callback intervals, dashboard collection/application and maximum image paint time. Collection is background time; callback interval is elapsed time between timer calls, not render duration.

Keep Smooth live selected for the independent preview. Matched AI overlays remains available at the detector rate. Detector blob, count crossing rule, schedule, foreign alarm logic, and stream diagnostics are unchanged. CSV exports are asynchronous; if an export fails the committed SQLite data remains the source for recovery.
